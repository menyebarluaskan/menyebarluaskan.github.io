This is my working project that actually vibe-coded. I'm using
[Open Code](https://opencode.ai/) to develop it. The model that I'm using
is Big Pickle, the free tier one. That's why I open sourced this code because
these free tier model might train on the code that I develop using this.

This project started after the budget tracker app that I'm using have a
change that makes it doesn't do cloud sync like it used to. Also, there is
a feature that I wanted but unavailable in most of the budgeting app or it was
being paywalled.

Features:

- Transaction tracker
- Transaction tagging
- Budget creation based on transaction tags
- Budget estimation, chart, and spending recommendation
- Account Management
